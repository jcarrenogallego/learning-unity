# Cómo contribuir

Gracias por ayudar a mejorar este repositorio didáctico.

## Flujo obligatorio

- El propietario puede actualizar directamente las ramas protegidas.
- Cualquier otra persona debe crear una rama y abrir un pull request.
- El PR necesita CI correcto, una aprobación y todas las conversaciones resueltas.
- No se permiten force-push ni eliminación de ramas protegidas.

## Antes de abrir el PR

- Escribe documentación en español sencillo.
- Explica términos técnicos la primera vez que aparezcan.
- Añade diagramas Mermaid cuando aclaren un flujo o una relación.
- Comprueba que no se incluyen carpetas generadas por Unity ni secretos.
- Usa Conventional Commits.

## Nombres de ramas

- `docs/descripcion`
- `feat/descripcion`
- `fix/descripcion`
- `test/descripcion`
